# RemixTree

RemixTree is an open-source creative network built around remix lineage and durable attribution.

## Implemented foundation

- immutable published work versions;
- four plain-language permission presets;
- multi-source remix publication;
- frozen source permission and credit snapshots;
- transitive, deduplicated credit manifests;
- initial schema, typed HTTP boundary and tests.

Permission presets are creator declarations, not legal verification or advice.

## Run locally

```sh
npm install
npm test
npm run dev
```

Open http://localhost:3104. Planned work is listed in [the roadmap](docs/ROADMAP.md).
