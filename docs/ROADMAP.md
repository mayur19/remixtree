# Delivery roadmap

1. **Foundation:** published versions, permission snapshots, source edges, credit traversal and schema.
2. **Creator tools:** accounts, drafts, media validation, collaborators and publication.
3. **Lineage:** graph and accessible list, collections, profiles, search and discovery.
4. **Participation:** challenges, voting, notifications and curation.
5. **Trust and release:** disputes, moderation, export, accessibility, deployment and browser coverage.
